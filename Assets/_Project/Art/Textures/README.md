# Textures

Use PBR texture sets where possible:

- Albedo/BaseColor
- Normal
- Metallic
- Smoothness or roughness
- Ambient occlusion

Keep source texture names aligned with model/material names, for example:

- `T_Draugr_A_Albedo.png`
- `T_Draugr_A_Normal.png`
- `T_Draugr_A_MetallicSmoothness.png`
